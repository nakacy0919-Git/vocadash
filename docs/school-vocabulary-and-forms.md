# School vocabulary and word forms (2026-11-28)

- 104 independently authored supplemental headwords, 208 examples and Japanese translations, stable existing IDs. Existing image indexing resolves exact filename matches. Existing CEFR field is retained; new non-CEFR-J words use editorial difficulty estimates.
- VocaSheet school-level grouping is an independent provisional pedagogical grouping, not an official Ministry or textbook list. Elementary selection is not a verified 600–700-word curriculum; the CEFR fallback does not establish school attainment.
- Curated word forms are POS-specific and do not generate unverified forms. Search accepts registered inflections and contraction expansions. Not exhaustive.
- The optional local supplement importer accepts vd-private-study-list-v1 JSON. Files are stored only in the browser localStorage, not uploaded. It is a separate personal study list, not a canonical vocabulary batch. No textbook source list is included in the repository.
- New draft vocabulary requires independent editorial review; all public-facing examples are original.
