# UniMorph English inflection subset

Source: UniMorph English (`eng`), https://github.com/unimorph/eng/tree/66e0e9e8e2dcd196da081a25a48e5c1fe3d8b49b, source README credits Wikipedia. Licensed under Creative Commons Attribution-ShareAlike 3.0 https://creativecommons.org/licenses/by-sa/3.0/ .

The three `src/data/inflection-lexicon-*.json` files are adapted subsets (selected lemma/POS/tag rows, duplicate forms and obvious non-form metadata removed, converted to JSON). They are distributed under the same CC BY-SA 3.0 license. This applies to the separate lexicon files, not the independently authored Japanese explanations, examples, or app code. Source forms are lexical attestations, not individually sense-verified. Data pinned to the commit above; no textbook data used.
