# VocaDash morphology system

All active sense IDs receive a POS-aware morphology profile. Existing word IDs, CEFR levels and learning records are unchanged. Editorial tables override the separate UniMorph reference subset; the latter is CC BY-SA 3.0 (see inflection-lexicon-LICENSE.md). Reference forms are lexical, not sense-verified. Conditional forms have explicit usage notes and unconfirmed comparison constructions are not indexed as exact search forms. Review entries display the lemma, not invented forms. Invariant entries explain the grammatical class. The audit counts every active sense and reports outstanding editorial items; run npm run audit:word-forms -- --output /tmp/vd-forms-review.json. VocaSheet and Universe expose the profile. The code and original vocabulary are separate from the licensed subset. No textbook data is copied.

For registered records only, conservative regular spelling candidates are now shown as `候補` when the lexical reference is missing; they are excluded from exact form searches and audio. Ambiguous stress/irregular endings remain review items. Source forms and candidates are not a claim of full sense-level proofreading. POS aliases (number, modal auxiliary, auxiliary verb, verb form, contraction) are handled explicitly.
